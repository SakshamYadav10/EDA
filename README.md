An exploratory data analysis of the Body
Performance dataset, a tabular dataset containing physical
measurements and exercise performance indicators for over
13,000 individuals. The aim was to investigate how body
composition and physical capability relate to overall perfor
mance class. The analysis applied data processing, descriptive statistics, visualisation, feature engineering, Principal
Component Analysis (PCA), and KMeans clustering. The
results suggest that body fat percentage is negatively associ
ated with performance-related variables such as sit-up count
and broad jump distance, while strength and explosive
power variables tend to move together. PCA revealed mean
ingful multidimensional structure in the data, and cluster
ing identified distinct physical-performance profiles. Over
all, the dataset was found to be well-suited for EDA because
it is large, mostly numerical, interpretable, and rich enough
for both statistical and visual analysis.
